# Jack Mazzini

### AI-Native Systems Integrator & Technical Prototyper

I build unusual products at the intersection of **AI, software and physical hardware** — local AI systems, edge-compute nodes, native Android applications, connected devices, automation and practical electronics prototypes.

My strongest capability is **systems integration**: taking an idea that crosses unfamiliar technical boundaries and turning it into a demonstrable system by connecting hardware, Linux services, applications, AI models, APIs, sensors and user interfaces.

## Selected work

### [Sentient Core](https://github.com/thotsl4yer69/sentient-core)
Local-first edge AI on NVIDIA Jetson. Local inference, voice, memory, FastAPI services, MQTT/Redis integration, Linux deployment and a browser/PWA interface.

**Status:** Deployed prototype / active hardening  
**Focus:** Edge AI · Python · Linux · MQTT · Redis · local inference · speech

### [DRIFTER](https://github.com/thotsl4yer69/drifter)
Raspberry Pi vehicle-intelligence prototype combining OBD-II/CAN-oriented telemetry, diagnostics, logging, MQTT services and driver/operator interfaces.

**Status:** Hardware-integrated prototype / active hardening  
**Focus:** Raspberry Pi · vehicle telemetry · CAN/OBD-II · MQTT · deployment

### [Myceliyum](https://github.com/thotsl4yer69/Myceliyum)
Offline-first native Android field-research application for mycology, combining local reference data, maps/location, iNaturalist and environmental context.

**Status:** Application prototype  
**Focus:** Kotlin · Jetpack Compose · Room · OpenStreetMap · APIs · offline-first

### [HexPlayer](https://github.com/thotsl4yer69/Hexplayer)
A tangible media interface: tap an NFC tile and trigger the mapped digital music item through a Raspberry Pi-based player.

**Status:** Bench prototype  
**Focus:** Raspberry Pi · NFC · Python · SPI · physical computing · APIs

### [Akari Android](https://github.com/thotsl4yer69/akari-android)
Private, local-first Android energy diary demonstrating native application architecture, Room/DataStore persistence, CI, accessibility-minded QA and explicit data boundaries.

**Status:** Application prototype  
**Focus:** Kotlin · Compose · privacy-by-design · local data · CI · accessibility
