How to get started

1. Save an InvestigationDesk_Audio ZIP file to your phone.

2. Tap Import audio pack and choose the ZIP using Android's file picker.

3. Open any downloaded lesson. It will work in aeroplane mode, including lock-screen controls and background playback.

4. The new repair chapters can be spoken using Android's text-to-speech voice until their actual recordings are imported.

5. Keep a backup of your audio ZIP files. Removing the app also removes its private audio.
